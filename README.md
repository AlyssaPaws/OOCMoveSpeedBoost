# Out Of Combat Move Speed Boost (Continued)
A Rimworld mod that applies a configurable move speed multiplier to all pawns when outside of combat. 

Originally created by Murmur. 
maintained (and improved) with 1.6 and onwards by AlyssaPaws.


Details
----
The move speed of all pawns is increased when no active threat is detected. Any actively hostile pawns on a local map are considered as threats.
Pawns that aren't considered a threat are: dormant pawns (like dormant mechanoids), uninitiated buildings (like untriggered mechanoid turrets), insects when not actively attacking, and pawns that can't actually reach you.

The effect will be applied to all local maps, and disabled for all if any of them contain a active threat.
You can manually toggle the effect by using the button in the bottom right (under the time controls), as well as with a keybind (default '5', configurable in Options>Controls>Keyboard configuration)

Settings
-----
- Configure move speed multiplier (Default is 3x)
- Enable/Disable button in the bottom right to manually toggle the move speed effect
- Enable/Disable manual reactivation after the move speed effect is automatically disabled
- Enable/Disable automatic deactivation when any colonist is drafted
- Enable/Disable notification in the top left when the effect is disabled or re-enabled
